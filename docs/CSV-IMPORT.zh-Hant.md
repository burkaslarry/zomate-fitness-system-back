# [F001][S003] 直接匯入 Numbers 會員 CSV

1. 開 [學生管理](https://zomate-fitness-system-front.vercel.app/admin/students)，使用有學生匯入權限嘅管理員／櫃台帳戶。
2. 按「匯入 CSV／Excel」，選擇原始 `memberinfo.csv`。唔使人手刪除第一行 `Table 1`。
3. 檢查回傳嘅新增、更新、略過數量；有略過則閱讀各列原因。
4. 搜尋匯入嘅學生，核對姓名、香港電話、出生日期、性別、緊急聯絡資料。

支援 Numbers 額外加入嘅 `Table 1`／`表格 1` 標題及前置空行。真正欄名仍需使用 Fung／系統學生名單格式；收錢表唔會被當成學生名單。姓名中嘅逗號按正常 CSV 引號處理。

同姓名、同香港電話再次匯入會更新原有學生；同電話但不同姓名仍會略過，避免覆蓋錯人。冇提供 `lesson_balance` 或其他可選資料欄時保留現有資料；如果明確提供堂數（包括 0），會按既有規則調整餘額。

2026-10-23：用提供嘅原檔於獨立記憶體 SQLite 實測，首次 14 新增、0 更新、0 略過；再次 0 新增、14 更新、0 略過。呢項係隔離測試結果，未將該私人名單預先寫入正式資料庫。測試資料及原始名單不會放入 Git。
